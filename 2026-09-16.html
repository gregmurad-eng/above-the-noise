Lead Story

The frontier just publicly agreed to slow down — and priced its own IPO on it — Fortune, Bloomberg, MarkTechPost

On Friday 12 September, Anthropic CEO Dario Amodei published We Must Pace the Frontier, arguing that frontier labs must deliberately slow capability gains so alignment and evaluation work can catch up, and committing Anthropic unilaterally to the first step of a three-part plan: embedded evaluators — permanent, employee-level, badged access at Anthropic offices for a third-party team (he named METR as a candidate) empowered to publish findings without editorial control[1][2]. Inside 48 hours the pledge stopped being one lab's posture. Sam Altman said OpenAI would match the embedded-evaluator commitment; Demis Hassabis quote-tweeted the essay and endorsed the direction; Microsoft became the first hyperscaler to formally sign onto the pacing framework[2][3].

Monday 14 September, Microsoft published its MAI Code of Conduct for public consultation — a behavioural rulebook for its first-party models with absolute bans on cyberattacks, nuclear-weapons work, and deepfake production, plus a six-week comment window[3][4]. Satya Nadella's own X post announcing it was unambiguous about the frame: pacing is now Microsoft's stated stance, not a hedge[4]. And on the same Friday, Sam Altman told Fortune editor-in-chief Alyson Shontell that OpenAI's IPO will not happen in 2026, saying "given everything happening with safety, right now would be an ill-advised moment to go public"[5][6]. A CFO-level walk-back on the largest expected AI listing of the year is what a pacing pledge looks like when it hits a balance sheet.

The analytical question is whether any of this survives contact with Q4 pricing pressure. Amodei's essay names two triggers behind the reversal: recursive self-improvement — models measurably helping build the next generation — and the OpenAI–Hugging Face agent-swarm incident as an industry-wide warning that misaligned swarms could produce catastrophic cyber damage inside 6–12 months[1][7]. Both are real. But every lab in the coalition has trillion-dollar-scale compute commitments landing on the same clock, and the only public pledge with teeth so far is Anthropic's embedded-evaluator seat inside its own building. Everything else is a code of conduct, a comment window, or a delayed prospectus. The pacing story is now falsifiable: within eight weeks, either a lab publishes a delayed release citing safety review, or the pledge is the polite version of "we could not have shipped that fast anyway."

So what: model roadmaps you are planning against will slip on safety-review grounds, not capability grounds. Pin the model version, region, and provider you depend on in a contract clause, and expect at least one deprecation window this quarter to be extended by four to eight weeks — plan renewals to that widened window rather than the last published date.

The Briefs

Cloudflare's mixed-use crawler block goes live on ad-supported pages — Cloudflare

The July-announced default that blocks "mixed-use" AI crawlers — those that blend search indexing with training and agent collection — on any page carrying advertising took effect Tuesday 15 September for new customers, new sites owned by existing customers, and all existing free-tier customers[8][9]. Google, Apple and Microsoft all run bundled crawlers; publishers who block Training now also lose search visibility until those companies separate the functions. Primary: Cloudflare's own policy page.

So what: if your product ingests public web pages via a mixed-use crawler, expect ad-page coverage to fall this week without a single line of code changing. Audit which user-agent your fetcher declares, and split search from training if you want a route back onto the ad-supported long tail.

Perplexity Portable Computer ships local on Windows RTX PCs — VentureBeat, SiliconANGLE

On 14 September Perplexity brought its Portable Computer agent — model, agent harness, orchestrator and scheduler — fully on-device to Windows PCs with an Nvidia GeForce RTX GPU carrying 24GB VRAM or more[10][11]. The Windows app ships a Qwen 3.8 27B variant post-trained for the agent loop and RTX-optimised. Available to Pro and Max subscribers via the Microsoft Store; zero token cost per action once running. Trade: VentureBeat and SiliconANGLE, corroborated.

So what: local computer-use agents are the first credible answer to per-call inference costs on high-volume, low-margin workflows. If you're building browser automation on rented API tokens, price a hybrid — local Qwen on capable clients, cloud fallback for the rest — before Q4 pricing renewals reset your margin math.

Google's Fairwind Program crosses 650 vetted defender partners — Google

The gated-access channel for Gemini 3.8 Flash Cyber paired with CodeMender — Google's autonomous patch-generation agent — now counts more than 650 participating governments, critical-infrastructure operators and platform maintainers, up from the initial announcement fortnight on 2 September[12]. Access is application-only; the model is deliberately unavailable outside the program. Primary: Google's own program page.

So what: if you run a critical-infrastructure product and haven't applied, the peer-defender population that can already generate verified patches inside minutes is now large enough to be a competitive gap on incident-response SLAs. Apply this quarter or price into your response times.

Apple ships rebuilt Siri backed by Google Gemini in iOS 27 — Forbes, Eastern Herald

Apple's rebuilt Siri began public beta rollout Monday alongside iOS 27, with server-side reasoning routed to a Google Gemini deployment and complex queries running against Apple's own AFM 3 Cloud Pro model on Nvidia hardware hosted in Google's cloud[13][14]. English-only beta with daily usage limits and a waitlist; a paid tier is signalled but not priced. Tier-1: Forbes, corroborated by Eastern Herald.

So what: if your app integrates App Intents or exposes shortcuts, expect a step-change in how many arbitrary phrasings Siri now routes to you — instrument your intent handlers for the widened match distribution before your users start reporting weird invocations you didn't design for.

CVE-2026-58138 — unauth RCE in Orkes Conductor, orchestrating agents in prod — Empirical Security

Orkes Conductor versions 3.21.21 through pre-3.30.2 carry an unauthenticated remote-code-execution flaw scored CVSS 9.8: inline workflow definitions accept JavaScript or Python expressions and execute them on the engine host with no auth wall[15]. The Netflix-derived workflow engine has found a second life orchestrating production AI-agent pipelines, which puts a lot of RAG and tool-calling systems in scope. Patch to 3.30.2 or later; block inline expressions at the reverse-proxy layer if you can't upgrade this week. Specialist: Empirical Security CVE-of-the-month.

So what: any agent orchestrator you inherited from a "just use the workflow engine" decision made in 2023 is now on your patch-tree. Audit which version is behind your MCP servers and CI job runners before Friday — the CVSS 9.8 unauth path is the exact class of bug that dies quietly and then loudly.
