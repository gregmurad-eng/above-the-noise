Lead Story

Cloudflare absorbs Deno — the runtime winds down in twelve months, Deno Deploy in six — Cloudflare[1]

Cloudflare and Deno jointly announced on October 9 that Deno — the TypeScript-first runtime from Node's original creator Ryan Dahl — is being acquired, with both companies publishing matching posts under the same title[2]. The strategic asset is not the runtime itself but celld, Deno's engine for Durable Objects and self-hosted compute, which Cloudflare plans to merge into workerd to unlock a self-hostable version of Workers and Durable Objects. On the Deno side, the open-source Deno runtime will see one more year of maintenance before being archived, and Deno Deploy — the hosted platform — shuts in six months. Deno KV, Deno Queues, and the standalone deno binary all converge toward Cloudflare's primitives.

Three things make this consequential beyond the standard acqui-hire template. First, this is the first visible break in the "independent JavaScript edge runtime" cohort that formed around 2020 — Deno, Bun, Vercel's Edge Runtime, Fly.io's firecracker fleet. The economics of running a global compute network as a standalone business always required either a cloud underneath you or a cloud buying you; Cloudflare's purchase answers which outcome won here. Second, Dahl now ships celld inside Cloudflare's dominant Workers platform, which means the "Deno-flavored" standards work (Web APIs on the server, native TypeScript, built-in test runner) effectively becomes the Workers roadmap. Third, and most pointed for anyone running agents at the edge: the six-month Deno Deploy sunset is a hard migration clock for every scheduled job, cron handler, and MCP endpoint running there today — and Cloudflare has not yet published a Deno-Deploy-to-Workers API compatibility matrix.

The honest read for builders: Cloudflare just acquired both the right to shape the server-side JavaScript standards narrative and the right to tell a few thousand Deno Deploy teams where their next bill comes from. The "Workers API coverage" document that eventually drops will quietly determine which Deno Deploy applications migrate cleanly, which rewrite their edge layer, and which move to a competitor who still exists next quarter.

So what: if your scheduled jobs, cron handlers, or MCP endpoints run on Deno Deploy, you have a six-month clock — start the Workers compatibility audit this week, because the migration guide Cloudflare has not yet shipped is on the critical path for everyone else too.

The Briefs

Memento 3 reports 100% on ARC-AGI-3 with a frozen LLM and an editable rulebook — arXiv (UCL & Huawei Noah's Ark)[3]

Zhao et al. published Memento 3 on October 8 — a model-based agent that scores a perfect 100.0 mean RHAE across all 25 public ARC-AGI-3 games using a frozen underlying LLM. The learning happens entirely in a natural-language rulebook that gets compiled to Python at runtime and iteratively refined via reflection on failures; the reported baseline for Claude Opus 5 under the same protocol is 40.7.

So what: if your agent system's "self-improvement" story is finetune-on-trace, this paper is the clearest argument this year for moving that logic into an externalized, versioned, auditable rulebook — weights that don't change can be gated and signed; weights that silently drift cannot.

Microsoft ships Decision-1 — a probability-returning model in Azure Foundry — Microsoft Tech Community (Azure AI Foundry Blog)[4]

Announced October 9, Decision-1 is a Qwen3.5-9B post-trained to return calibrated probabilities over fixed answer sets — yes/no, multiple-choice, rubric grades — instead of generating free-form text. 32K context, hosted-only (no weights), $0.042 per million input tokens, output tokens free. Microsoft publishes P50 latency figures claiming 35× faster than GPT-6 Sol for the same classification tasks.

So what: if your agent pipeline currently pays frontier-model rates to have Opus or GPT-6 classify, route, or score a step, this is a two-order-of-magnitude cost drop for that specific subtask — and calibrated probabilities let you threshold confidence instead of regex-parsing a chatty JSON response.

Alibaba's Qwen team releases Qwen-Image-2.1-Turbo — open-weight 8-step image model — QwenLM GitHub[5]

Dropped October 9. Same 7B visual architecture as Qwen-Image-2.1, but with an 8-step denoising schedule at CFG=1 baked into weights — down from 40 steps on the base — producing roughly a 5× speedup at matched quality for text-to-image and multi-reference edit tasks. Weights live on Hugging Face and ModelScope under the Qwen Research License (commercial use requires permission); API available via Alibaba Cloud Model Studio at CNY 0.1 per image.

So what: if latency or per-image API cost was gating a creative pipeline on your product, this is a self-hostable path to near-realtime generation on a single workstation GPU — but read the Qwen Research License before you ship it in anything paid.

Gemini Flash 3.5 and 3.7 are being auto-routed, silently, to 3.6 and 3.8 — Google AI for Developers[6]

Per Google's October 8 Gemini API changelog, requests to gemini-3.7-flash now auto-route to gemini-3.8-flash, and gemini-3.5-flash auto-routes to gemini-3.6-flash. Nothing changes in your SDK call. Nothing in the response payload tells you the swap happened.

So what: every scheduled job pinned to a 3.5 or 3.7 Flash string is now hitting different weights with different tokenization, different token counts, and different pricing — audit your model-string constants today, because prompt-cache keys may have invalidated and the first signal will be a cost or regression spike nobody can root-cause.

Voices

Yoshua Bengio, Turing Award laureate and founder of LawZero/Mila, in an essay written exclusively for Transformer[8] published October 8, 2026:

"If you truly prioritize safety, it is time for you to leave frontier AI companies."

Bengio's argument is that safety and interpretability work inside the frontier labs has become structurally compromised — not because the researchers are insincere, but because the organizations are no longer organized around the possibility that they are wrong — and that the serious work now lives in national safety institutes, LawZero-style independent labs, and mission-driven orgs willing to publish findings their employer will not. Published a day before Anthropic disclosed four classes of agent misbehavior in its own evaluations[9], the essay reads as the sharpest contemporary rebuttal to the premise that frontier-lab self-regulation is sufficient.

So what: if your product's safety story leans on "the lab tested it before shipping", the Bengio essay plus the Anthropic disclosure give you a dated receipt that the lab's own senior safety voices consider that posture inadequate — plan to carry the audit load yourself, or to buy it from someone whose paycheck does not depend on the lab you are auditing.
