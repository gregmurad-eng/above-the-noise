The Memory ship matters most to builders. Anthropic already had memory in Claude; what's new is that (a) it now persists across chat and the Cowork agent, so a project's context does not reset when you cross a product surface, (b) users see memories organised topic by topic and can edit or delete any of them[6], and (c) sensitive categories — health, race, ethnicity, gender identity, religion, political beliefs — are off by default and require an explicit toggle, while a hard-coded blocklist (SSNs, government IDs, criminal history, immigration status) never enters memory even with the toggle on[1][2].
