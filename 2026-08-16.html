Lead Story

DeepSeek raises API prices up to eleven-fold — the year's pricing floor just moved

At 16:00 UTC today, DeepSeek's new API rate card takes effect for V4-Flash and V4-Pro, ending the run of aggressive undercut pricing that made the Hangzhou lab the reference price for every frontier-adjacent API in the market.[1] V4-Pro output tokens rise from $0.87 per million to $1.98 off-peak and $3.96 at peak — a 4.6× jump at the top of the band. V4-Flash output goes from $0.28 to $0.66 off-peak and $1.32 at peak. Cache-miss input tokens on V4-Pro move from $0.435 to $1.32 at peak. The largest headline number — the roughly 1,100% increase — is on V4-Pro cache-hit input tokens, which move off effectively-free.[1][2]

The move also introduces peak/off-peak tiering on a frontier API for the first time from a major lab. Peak windows are 01:00–04:00 and 06:00–10:00 UTC; everything else is off-peak. DeepSeek's stated rationale is to "revise and adjust the pricing to allocate resources more reasonably," which is the polite phrasing for saying that at January 2026 prices the API was congested at every hour of every day and margin was negative.[2][3]

Two things about this matter beyond the DeepSeek billing shock. First, this is the pricing floor of the year moving up 4× overnight. Every AI vendor whose pricing is anchored to "DeepSeek is $X, so we can be $2X or $3X and stay competitive" now has permission to reprice — Anthropic's Claude 5 at $50 per million output tokens[2] is no longer facing an 60× undercut, it is facing a 12× undercut, and the calculus behind every one of this year's promotional discount SKUs just changed. Second, peak/off-peak tiering on a frontier API is a template. If it works commercially for DeepSeek — meaning developers shift workloads to 04:00–06:00 UTC and 10:00–01:00 UTC to save half — expect other API vendors to try the same in Q4. Time-of-day pricing is how cloud storage got sold in the 2010s; it is arriving in inference.

Read this with the other capital-allocation stories of the week: Anthropic in talks to buy the Israeli efficiency lab Decart for $6 billion,[4] Anthropic and IBM landing an Elite-tier consulting alliance to book enterprise LLM revenue through the IBM Consulting Advantage stack.[5] The frontier is done chasing free traffic. This is the quarter it starts pricing itself like software.

If your nightly batch job or agent stack runs against DeepSeek, re-run today's cost model on the new rate card before 16:00 UTC — anything scheduled inside 01:00–04:00 or 06:00–10:00 UTC now costs 2× what it did last week. If your commercial pitch has been "we're cheaper than OpenAI because we route to DeepSeek," that margin story compresses today and your board deck needs new numbers by Monday.

Voices

Simon Willison, independent researcher and Django co-creator, writing on his weblog on August 14 about a technique first described by Doug Turnbull for classification-with-large-vocabularies:[10]

"Tell the model to output tags without any details of the existing vocabulary, then use vector embeddings against the existing corpus to find the concrete tags that are closest…"

The reason this matters beyond content tagging is that it inverts a whole class of prompt-engineering habit. The instinct is to constrain the model with the exact permitted answer set stuffed into context; the technique here says do the opposite — let the model invent freely, then snap-fit its output to your ontology afterwards with embeddings. It works because embedding proximity is a cheaper and more forgiving alignment surface than in-context constraint. Every builder shipping structured output — JSON schemas, category selection, taxonomy assignment — has one of these two patterns wired into their stack and probably has not stopped to test which is actually better on their data.

Pick one live classifier or tagger in your product this week and run Willison's inversion side-by-side against your current constrained-vocabulary prompt on the same test set — it takes an afternoon and either validates your current prompt or hands you a cheaper, better one.
